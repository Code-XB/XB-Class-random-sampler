# 随机抽取器

一个为课堂场景设计的现代化随机点名工具，基于 **Python + PySide6** 构建，界面美观、功能完善。

## ✨ 功能特性

- 🎲 **随机抽取**：炫酷的滚动动画效果，支持单人 / 多人同时抽取
- 🔁 **去重抽取**：本轮已抽同学自动排除，确保公平覆盖
- 👥 **分组管理**：自由创建分组，拖拽调整学生归属
- 🔍 **拼音筛选**：支持汉字、拼音全拼、拼音首字母快速定位学生
- 📋 **多配置切换**：可为不同班级 / 场景创建独立配置，一键切换
- 📜 **历史记录**：按日期 / 时间查看过往抽取结果，支持一键清空
- 📥 **灵活导入**：支持 TXT 文件导入、从已有配置导入（含分组）
- 🎨 **暗色主题**：精心设计的深色 UI，护眼且美观

## 🖥️ 运行环境

- Python **3.8+**
- Windows / macOS / Linux（跨平台）

## 🚀 快速开始

### 方式一：双击启动（Windows）

直接双击项目根目录下的 `启动.bat`，脚本会自动检测并安装依赖，然后启动程序。

### 方式二：命令行运行

```bash
# 1. 克隆或下载项目后，进入项目目录
cd 随机抽取器

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动程序
python main.py
```

## 🛠️ 使用说明

### 基本抽取流程

1. 点击 **"选择学生"** 导入或手动添加名单，可按分组勾选参与抽取的学生
2. 设置 **抽取数量** 和是否 **去重抽取**
3. 点击 **"开始抽取"** 即可

### 管理多个班级

点击 **"设置"** 打开配置管理：
- **配置管理** 标签页：新建 / 重命名 / 删除 / 切换配置
- **名单管理** 标签页：编辑分组、从 TXT 导入、从其他配置导入

### TXT 名单格式

支持以下任一分隔符：
回车、空格、英文逗号 `,`、中文逗号 `，`、中文顿号 `、`

示例：
```
张三, 李四, 王五
赵六
钱七、孙八
```
